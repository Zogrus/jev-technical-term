# 技術用語ガイド — セミナーや解説動画を聞きながら、技術用語の解説がその場に流れてくる

YouTubeの解説動画やZoomのセミナーなどを聞いているとき、**知らない技術用語が出てきて、そこから先の話に置いていかれた**ことはありませんか。

このツールを開いておくと、話の中に出てきた**デジタル系の技術用語**(AI、Web、プログラミング、インフラなど)の**ひとこと解説**が、聞いているそばからカードになって流れてきます。
AI駆動開発などの技術を、動画やセミナーで学ぼうとしている人(非エンジニアを含む)向けに作りました。

- 判定に使うAIは、TypeSafe AI の新しいモデル **[Jev](https://docs.typesafe.ai/introduction)** だけです(2時間の視聴で約$0.02)
- 文字起こしは **Chromeの内蔵機能**で行うので、追加の契約もキーも要りません
- 技術用語集は**約1,370語**を同梱。初級・中級・上級のレベルで、出す量を選べます
- 「もう知ってる」を押した用語は出なくなり、用語集にない語は自分で登録できます

> **どんなふうに動くか**は、[初心者向けの紹介ページ(docs/jev-for-beginners.html)](docs/jev-for-beginners.html) を開くと図つきで分かります。
> Jevで何ができて何ができなかったかの検証記録は [docs/jev-learnings.md](docs/jev-learnings.md) にあります。

## 仕組み(ざっくり)

```
聞いているタブの音声 ──▶ Chromeの音声認識 ──▶ 技術用語集(約1,370語)と照合 ──▶ 紛らわしい語だけ Jev に
                                                    (手元のプログラム)         「技術用語? 日常語?」と質問
                                                                                     │
                                                          画面にひとこと解説のカード ◀──┘
```

たとえば「スキル」という言葉が出たとき、「Claude Codeのスキル機能」の話なら解説を出し、「プレゼンのスキル」の話なら出しません。この見分けだけをJevに任せています。

## 必要なもの

| もの | 備考 |
|---|---|
| **Google Chrome**(または Edge) | Mac / Windows どちらでも可 |
| **Python 3**(3.10以上) | 追加のライブラリは不要。[python.org](https://www.python.org/downloads/) から入れられます。Windowsではインストール時に「Add python.exe to PATH」にチェック |
| **JevのAPIキー** | [TypeSafe AI](https://docs.typesafe.ai/introduction/quickstart) で取得(2026年9月時点で早期アクセス) |

## セットアップ(3ステップ)

1. **このリポジトリを手元に置く**
   - `git clone https://github.com/Zogrus/jev-technical-term.git`
   - または、GitHubの「Code」→「Download ZIP」で落として展開
2. **APIキーを書く**
   - `.env.example` をコピーして `.env` という名前にし、`JEV_API_KEY=` の右側にキーを書く
3. **起動する**
   - Mac: `start.command` をダブルクリック(初回は「開発元を確認できない」と出たら、右クリック→「開く」)
   - Windows: `start.bat` をダブルクリック
   - ターミナルから: `python3 app/server.py`(Windowsは `python app\server.py`)

Chromeで http://localhost:8765 が開けば準備完了です。

### つまずいたら、AIに頼む

Claude Code、Codex、Cursor などを使っている人は、リポジトリのフォルダで次のように頼めば、セットアップから起動までやってくれます。

```
このリポジトリの README.md と AGENTS.md を読んで、私の環境でセットアップして起動してください。
JevのAPIキーは持っています。
```

## 使い方

1. **別のタブ**で、動画やセミナーを再生します
   - Zoomは**ブラウザ版**で参加してください(デスクトップアプリの音声は、タブとして共有できません)
2. 技術用語ガイドの画面で「**聞いているタブの音声で開始**」を押します
3. 共有ダイアログで「**Chromeタブ**」→ 聞いているタブを選び、「**タブの音声も共有**」をオン
4. あとは聞いているだけ。用語が出ると、カードが上から積まれていきます

| 画面の操作 | 説明 |
|---|---|
| 解説を出すレベル | 初級から全部 / 中級以上 / 上級のみ。分かってきたら上げる |
| 同じ用語の再表示まで | 5分 / 10分 / 20分。同じ用語のカードを連発しないための間隔 |
| もう知ってる(今後出さない) | その用語は以後出なくなる(このブラウザに記憶) |
| もっと調べる | Google検索を開く |
| 黄色いカード(用語集にない専門用語) | 調べた内容を書いて「用語集に登録」すると、次からは解説つきで出る |
| その他の操作 → 用語集に自分で追加 | カードが出なかった語も、用語と解説を入力して登録できる |
| その他の操作 → マイクで開始 | タブ共有ができない場合の代替。スピーカーの音をマイクで拾う |

## 用語集を自分好みにする

技術用語集は、ただのJSONファイルです。増やす・直す・レベルを変える、が自由にできます。

### 3分でできる: 画面から登録する

黄色いカード、または「その他の操作」の入力欄から登録すると、`glossary.user.json` に保存されます。
このファイルは自分専用で、同梱の用語集を更新しても消えません。

### ファイルを直接編集する

用語集は `glossary/parts/` に分野ごとのファイルで入っています。

| ファイル | 分野 |
|---|---|
| `01_pc_web.json` | PC・インターネット・Webの仕組み |
| `02_ai_concepts.json` | AI・LLMの概念 |
| `03_ai_products.json` | AI製品・企業・モデル名 |
| `04_ai_coding.json` | AI駆動開発・コーディングエージェント |
| `05_programming.json` | プログラミングの基礎 |
| `06_tools_git.json` | 言語・ツール・Git・チーム開発 |
| `07_db_infra.json` | データベース・インフラ・運用 |
| `08_sec_biz.json` | セキュリティ・ビジネス・UI/UX |
| `09_research_gaps.json` | 初心者がつまずきやすい語・スラング |

1語は1行で、こういう形です。

```json
{"id": "web_cookie", "level": 1, "display": "Cookie", "aliases": ["Cookie", "クッキー"], "sense": "Webサイトがブラウザに保存させる小さなデータ", "short": "Webサイトが、あなたのブラウザに保存しておく小さなメモ。ログイン状態の維持などに使われる。", "other": "お菓子のクッキー"}
```

| 項目 | 意味 |
|---|---|
| `level` | 1=初級 / 2=中級 / 3=上級 |
| `display` | カードの見出し |
| `aliases` | 文字起こしの中で探す表記。音声認識は「グラファナ」「フラバナ」のようにカタカナや聞き間違いで出るので、それも入れる |
| `sense` | 技術的な意味(短い名詞句)。Jevに「この意味で使われたか」を判定させるときの選択肢になる |
| `short` | 初心者向けのひとこと解説(1〜2文、90字以内) |
| `other` | 日常語としての別の意味がある場合だけ書く(例: コミット→「約束する」)。これがある語だけJevに聞く |

手順:

1. 該当分野のファイルに1行足す(書き方の詳細は [glossary/SPEC.md](glossary/SPEC.md)。特に「別名のルール」は誤爆を防ぐために大事です)
2. `python3 glossary/validate.py glossary/parts/<ファイル>.json` で形式をチェック
3. サーバーを起動し直す

**AIに頼む場合の例:**

```
glossary/SPEC.md のルールに従って、glossary/parts/07_db_infra.json に
「コネクションプール」「デッドロック」「レプリケーション」を追加して、validate.py を通してください。
```

分野ごと丸ごと作りたいときは、`glossary/briefs/` に、同梱の用語集を作ったときの指示書があります。参考にしてください。

みんなの役に立ちそうな用語は、プルリクエストで送ってもらえると助かります。

## こんなときは

| 症状 | 対処 |
|---|---|
| 「開始」を押しても文字起こしが始まらない | 共有ダイアログで「タブの音声も共有」がオンになっているか確認。Chromeを最新版に更新(タブ音声の認識は新しめの機能です) |
| `start.command` がテキストエディタで開いてしまう(Mac) | ZIPで落とすと実行権限が外れることがあります。ターミナルでリポジトリのフォルダに移動し `python3 app/server.py` で起動するか、`chmod +x start.command` を一度実行 |
| `python3` / `python` が見つからない | Pythonを入れる。Windowsは「Add python.exe to PATH」にチェックして再インストール |
| 「判定エラー: 401」 | `.env` のAPIキーが間違っているか、空。`.env.example` をコピーして書き直す |
| 「判定エラー: 429」 | Jevの利用上限。少し待つと回復 |
| カードが多すぎる | レベルを「中級以上」にする / 再表示の間隔を長くする / 「もう知ってる」を押す / 「用語集にない専門用語も拾う」を外す |
| Zoomのデスクトップアプリで聞いている | ブラウザ版で参加し直すか、「マイクで開始」でスピーカーの音を拾う |
| 音声認識の精度が悪い | Chromeの内蔵機能の限界です。聞き間違いの表記は `aliases` に足すと拾えるようになります |

Windowsでの起動(`start.bat`)は、まだ実機で確認できていません。動かなかったら Issue で教えてください。

## 利用にあたって(プライバシー・料金・免責)

- 音声の文字起こしは、Chromeの音声認識(Googleのサーバー)で行われます
- 文字起こしのテキストは、用語の判定のために TypeSafe AI のAPIへ送られます。**それ以外のAIサービスは使っていません**
- テキストは保存されません(判定のたびに送って捨てます)
- Jevの料金は入力100万トークンあたり$0.042(2026年9月時点の公称)。実測では2時間の視聴で約$0.02でした
- **Zoomなどのセミナーや会議で使うときは、主催者側のルール(録音・録画・文字起こしの可否など)に従ってください。** 社外秘の内容を扱う場では、所属先のルールも確認してください
- 本ツールは現状のまま提供されるもので、動作や判定結果の正確さを保証しません。利用によって生じたいかなる結果についても、作者は責任を負いません。各自の判断と責任でご利用ください
