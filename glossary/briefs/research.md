Web調査の依頼です。作業ディレクトリは、このリポジトリのルートです。

## 背景
AI駆動開発(Claude Code、Cursor、バイブコーディング等)の勉強会や動画を聞く**初心者・非エンジニア**向けに、リアルタイムで技術用語の解説を出すツールを作っています。その用語集(目標1,000語)に入れるべき語を、実際の声から洗い出したい。

## 調べてほしいこと
WebSearch / WebFetch を使い、日本語の情報源を中心に調べてください(note、Zenn、Qiita、はてなブログ、X(Twitter)の投稿を引用・まとめている記事、Togetter、connpassの勉強会ページ、YouTubeの解説動画のタイトルや概要、企業のオウンドメディア等)。

1. **初心者・非エンジニアが「わからない」「つまずいた」と言っている用語**
   - 検索例: 「AI駆動開発 初心者 用語 わからない」「バイブコーディング 非エンジニア つまずき」「Claude Code 非エンジニア 挫折」「Cursor 初心者 わからない 用語」「プログラミング未経験 AI 開発 壁」「環境構築 挫折 非エンジニア」「ターミナル 怖い 初心者」
2. **AI関連の発信者がよく使う言葉・流行語・スラング**(初心者がXやnoteの投稿を読んで理解したい語)
   - 検索例: 「AI 用語集 2026」「生成AI バズワード」「Claude Code 用語集」「AIエージェント 用語 解説」「バイブコーディング 用語」「AI駆動開発 キーワード」。例: コンテキストエンジニアリング、ハーネスエンジニアリング、AIスロップ、エージェンティック、壁打ち、丸投げ、自走、Ralph loop のような新語。
3. **AI駆動開発の勉強会(Claude Code Meetup、AI駆動開発勉強会、Cursor Meetup 等)のLTタイトルや概要によく出る語**
4. **既存の初心者向け用語集に載っている語**(AI用語集、IT基礎用語集、Web制作用語集、非エンジニア向けIT用語)

## 出力
`glossary/research_terms.md` に、次の形式でまとめてください。

```
# 調査結果: 用語集に入れるべき語
## 1. 初心者がつまずいている語
- 用語 — どんな文脈でつまずいているか(1行) [出典URL]
## 2. 発信者がよく使う語・新語
## 3. 勉強会で頻出の語
## 4. 既存の用語集に載っている基本語(抜粋)
## 所感
(初心者のつまずきの傾向、用語集づくりへの示唆を5〜10行)
```

- 用語は**合計300語以上**を目標に。実際に見つけた語を優先し、推測で水増ししない。
- 出典URLを付ける(1語ごとでなく、まとまりごとでも可)。
- 最初に既存の用語集 `glossary.json` を読み、そこに**すでにある語は省くか「既存」と印を付ける**。
- Xの投稿は直接検索できないことが多い。取得できなかった場合はその旨を書く。
- 他のファイルは編集しない。最終報告は、見つけた語数と、特に重要だと思った発見を数行で。
